# Atajos de teclado

**🌐 [English](../../en/reference/keyboard-shortcuts.md) · Español**

> El set completo de atajos de teclado de AmoxSQL, agrupado por categoría. El mismo listado vive en el diálogo **Help** (Ctrl+Shift+/, o menú de la aplicación → Keyboard Shortcuts).

## Qué es

AmoxSQL está pensado para operarse con el teclado. Esta página lista todos los atajos disponibles, tal como aparecen en la pestaña **Atajos** del modal de Ajustes (abre Ajustes con **Ctrl+,**). Los atajos son globales de la app salvo los de la sección **Editor**, que actúan cuando el foco está en el editor de código.

## General

| Atajo | Acción |
|---|---|
| Ctrl + K | Paleta de comandos |
| Ctrl + P | Saltar a un archivo, tabla o columna |
| Ctrl + Shift + P | Paleta de comandos (alias) |
| Ctrl + , | Ajustes |
| Ctrl + Shift + / | Esta lista |

## Tips y gemas

- **La paleta de comandos manda:** **Ctrl+K** abre acciones rápidas buscables — el atajo que recordar cuando no recuerdas los demás.
- **Selección = ejecución parcial:** con texto seleccionado, **Ctrl+Enter** ejecuta solo esa selección.
- **Zoom global:** **Ctrl +/-/0** escala toda la interfaz, no solo el editor.
- **La referencia siempre está a mano:** **Ctrl+Shift+/** abre este mismo listado dentro de la app.
